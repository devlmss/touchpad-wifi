# Touchpad Wi-Fi

Touchpad Wi-Fi transforma um celular Android em touchpad e teclado remoto para
controlar um computador Windows pela mesma rede Wi-Fi local.

**Desenvolvedor:** Leonardo Moreira  
**Distribuição:** gratuita  
**Código-fonte:** proprietário e não publicado

## Downloads

Os arquivos de instalação serão disponibilizados na página
[Releases](https://github.com/devlmss/touchpad-wifi/releases), sem exigir uma
conta GitHub:

- Android: `Touchpad-Wi-Fi.apk`
- Windows: `TouchpadWiFi-Setup.exe` (instalador) e
  `TouchpadWiFiServidor.exe` (versão portátil)

O APK Android 1.0 foi recompilado para usar o crédito público “Leonardo

## Funcionalidades

- Movimento do cursor, cliques, clique duplo, rolagem e arrastar e soltar.
- Gestos de um a quatro dedos configuráveis no Android.
- Teclado nativo do Android e atalhos remotos.
- Pareamento local do celular com o computador por QR Code.
- Sensibilidade e ações configuráveis, salvas no celular.

## Instalação e uso

### Android

Baixe `Touchpad-Wi-Fi.apk` na página de Releases, abra o arquivo e siga o
aviso do Android para instalar aplicativos obtidos pelo navegador. Conecte o
celular e o computador à mesma rede Wi-Fi.

### Windows

Execute `TouchpadWiFi-Setup.exe` e siga o assistente. Ele oferece atalhos no
Menu Iniciar, inicialização com o Windows e abertura do servidor ao concluir.
No computador, abra o servidor e clique em **Iniciar servidor**. No app, abra
Configurações e leia o QR Code exibido.

Se o computador mudar de rede, reinicie o servidor e leia o QR Code atualizado.

## Segurança e privacidade

A conexão funciona na rede local e não requer conta ou serviço externo. O
tráfego não é criptografado; use somente em uma rede confiável. O código de
pareamento não faz parte deste repositório nem dos downloads.

O instalador e o executável Windows não têm assinatura digital de uma
autoridade certificadora. O Windows, especialmente o Smart App Control, pode
bloqueá-los ou exibir avisos. Não desative as proteções do Windows para
executá-los.
